# Прошивка: main fd23599 (у банері git=fd23599), збірка в Docker (stm32-builder, arm-none-eabi-gcc 10.3.1),
# firmware.bin sha256 a7a700f4b1e46e1eb38e34b59b162f4c021dde4d07141c1c2632637e9fa19993.
# Пробні прогони scripts/uart_capture.py перед S1–S3 (не доказ S1). Стан стенда: UNLOCKED, двері відчинені, без дій оператора.
# Знахідка: прийом команд UART губить і спотворює команди в штатному циклі, без навантаження.
# Рядки LOAD, ENV і повторювані EVT uart_cmd_rx/tx пропущено. Час ліворуч — від старту запису на ПК.
#
# Причина (код): Platform_UartGetChar() опитує USART2 з task_uart(), без переривання RXNE і без буфера.
# Між опитуваннями цикл блокують: security ~1,57 мс кожні 20 мс, env (DHT11) ~41 мс кожні 2 с,
# друк рядків printf (~87 мкс на символ). Якщо за цей час приходить 2+ байти — ORE; скидання ORE
# читанням DR викидає й байт, що там лежав. Команда губиться цілком або частково.
#
# --- 1. Команди одним блоком (як із терміналу): 40 × "PING n\r\n" з випадковою паузою 0,3–0,9 с ---
sent=40 pong=31 lost=[1, 2, 11, 16, 18, 30, 32, 36, 39]
# unknown command 'G 16', HELP for list
UART rx_overrun=14 cmd_overflow=0
STAT name=security n=9838 min_us=8 avg_us=1563 max_us=10144
STAT name=env n=99 min_us=27379 avg_us=41307 max_us=41490
#
# --- 2. Частково прийнята команда змінює зміст: надіслано "PING 12", виконано "PING 1" ---
+   35.899s > PING 12
#           (відповіді немає — загублено цілком)
+   38.941s > PING 12
#           (відповіді немає)
+   41.941s > PING 12
+   41.945s PONG seq=1 t_us=35802240
#
# --- 3. Загублений \r лишає залишок у буфері рядка — наступна команда склеюється з ним ---
+   66.290s > MARK 2
#           (відповіді немає: дійшло лише 'M', \r загублено)
+   69.346s > MARK 2
+   69.352s # unknown command 'MMARK 2', HELP for list
#
+    0.000s > STATS RESET
+    0.006s # unknown command 'S RESET', HELP for list
#
# --- 4. Команда одразу після відповіді (плата ще друкує EVT) губиться ---
+   72.577s STATS_END
+   72.578s > MEM
#           (відповіді немає; повтор через 3 с — HEAP arena=1468 used=1468 free=0)
#
# --- 5. Порівняння на ПК: 81 команда (80 × PING n + STATS) після тиші 0,2 с на лінії ---
# пауза між символами | загублено з першої спроби | приріст rx_overrun
# 0 (одним блоком)    | 7 з 81                     | +11
# 5 мс                | 0 з 81                     | 0
#
# --- 6. Пробний S1 1 хв з RESET: uart_capture.py з типовими налаштуваннями ---
# (тиша 0,2 с, пауза 5 мс між символами, \r перед командою, перевірка відповіді, до 3 спроб)
+    7.4 с # BUILD отримано, надсилаю --start
+    7.501s STATS,reset
+    7.784s EVT t_us=1696638 name=mark_1
+   60.541s UART rx_overrun=0 cmd_overflow=0
+   60.552s STATS_END
+   60.860s HEAP arena=1468 used=1468 free=0
# Усі 4 команди — з першої спроби; parse_uart_logs.py читає сирий лог (git=fd23599).
