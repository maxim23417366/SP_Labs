## 3. Бюджет живлення та струмове навантаження

* **Джерело 5V (USB / зовнішній БЖ):** 
  Використовується для живлення сервоприводу **SG92R**. 
  *Обґрунтування:* Піковий пусковий струм сервоприводу під час руху засувки сягає **800 мА**. Живлення його від лінії 3.3V МК призведе до просадки напруги нижче 2.7В та brown-out перезавантаження мікроконтролера.

* **Джерело 3.3V (Стабілізатор LD39050PU33R на Nucleo):**
  Максимальний струм стабілізатора плати: **500 мА**.
  * OV7670 (Камера): робочий ~40 мА.
  * MPU-6050: робочий 3.9 мА.
  * W25Q64JV (Flash): запис/стирання 25 мА (піковий), читання 15 мА.
  * HC-SR501 (PIR): < 0.1 мА.
  * STM32F411 (МК): ~20 мА на 96 МГц.
  **Загальне споживання по 3.3V:** ~90 мА. 
  **Запас по струму:** 500 мА - 90 мА = **410 мА (запас 82%)**. Струму достатньо.

## 4. Параметри шин та дерево тактування

Джерело: **HSE 8 МГц** (Bypass від ST-LINK) -> PLL -> **SYSCLK 96 МГц**.

* **I2C1 (для MPU-6050 та OV7670):** Режим **Standard Mode (100 kHz)**. Розрахунок прескейлера виконується апаратно в CubeMX. 
* **SPI2:** Режим **SPI Mode 0** (CPOL=0, CPHA=0). Дільник (Prescaler) налаштовано на 16 (APB1 48 МГц / 16 = **3 МГц** частота SCK). Це задовольняє вимоги W25Q64 (макс 133 МГц) та дозволяє стабільно читати дані на бредборді.
* **MCO1 (Тактування камери):** PLLCLK (96 МГц) / 4 = **24 МГц** (XCLK камери).
* **TIM3 (PWM Серво):** Частота шини APB1 (96 МГц, оскільки множиться х2). Prescaler = 96. Частота таймера = 1 МГц (тік 1 мкс). Період (ARR) = 20000. Це дає рівно **50 Гц**.

## 5. Схема підключення (Структурна)

```text
======================================================================
                         NUCLEO-F411RE (STM32F411RET6)
======================================================================
                                  |
 [ Джерело 5V (USB/Ext) ]---------+------> [ SG92R Сервопривід ] (Живлення мотора)
                                  |
 [ Джерело 3.3V (Nucleo LDO) ]----+------> Живлення всієї логіки та сенсорів
                                  |
 [ Спільна Земля (GND) ]----------+------> GND усіх модулів та джерел
                                  |
======================================================================
  [ ШИНА I2C1 (Pull-up МК) ]      |
    PB8 (SCL) --------------------+------> [ MPU-6050 ] (Гіро/Аксель)
    PB9 (SDA) --------------------+------> [ OV7670 ] (Керування SCCB)
                                  +------> [ GY-89 ] (Резервний)
======================================================================
  [ ШИНА SPI2 ]                   |
    PB13 (SCK) -------------------+------> [ W25Q64JV ] (Flash-пам'ять)
    PB14 (MISO) ------------------+------>       |
    PB15 (MOSI) ------------------+------>       |
    PB10 (CS / GPIO Out) ---------+------>       |
======================================================================
  [ ПАРАЛЕЛЬНА ШИНА КАМЕРИ ]      |
    PC0 - PC7 --------------------+------> [ OV7670 ] (Шина даних D0-D7)
    PA8 (MCO1 - 24 MHz) ----------+------>       | (XCLK - Тактування)
    PA10 (TIM1_CH3) --------------+------>       | (PCLK - Піксель)
    GPIO (EXTI) ------------------+------>       | (VSYNC - Кадр)
    GPIO Out ---------------------+------>       | (RESET)
======================================================================
  [ ШІМ (PWM) ТА ДИСКРЕТНІ ]      |
    PA6 (TIM3_CH1) ---------------+------> [ SG92R Сервопривід ] (Сигнал ШІМ 50Гц)
    PA0 (EXTI0) <-----------------+------- [ HC-SR501 ] (PIR-сенсор OUT)
    EXTI <------------------------+------- [ MPU-6050 ] (INT)
    GPIO In (Pull-up) <-----------+------- [ Кнопки / Перемикач LOCK ]
======================================================================
  [ ЗВ'ЯЗОК З ПК ]                |
    PA2 (TX) / PA3 (RX) ----------+------> [ ST-LINK VCP ] (UART 115200)
======================================================================
````

## 6. Відхилені варіанти розкладки

1. **Одночасне використання PA0 та PB0 для переривань EXTI:** 
   *Причина відмови:* В STM32 піни з однаковим номером порту (PA0, PB0) підключені до одного мультиплексора лінії EXTI0. Неможливо слухати їх одночасно. Датчик PIR залишено на EXTI, а кнопки переведено на програмне опитування.
2. **Тактування камери (MCO1) від внутрішнього HSI (16 МГц):** 
   *Причина відмови:* HSI має нестабільну частоту при зміні температури, що викликало збої у синхронізації пікселів камери OV7670. Переведено на стабільний HSE 8 МГц від ST-LINK.
